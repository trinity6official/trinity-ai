# `raspberry_pi/` — Legacy / Optional Lightweight Path

This folder contains the older lightweight Raspberry Pi compatibility experiment. It is **not** the primary Trinity architecture.

The supported full runtime is the Apple Silicon Mac and all new architecture work should target the shared local runtime under `core/`.

Do not add cloud LLM fallbacks here. If Raspberry Pi support is revived later, it should act as a thin satellite/client or use the same local-first contracts rather than becoming a second independent Trinity brain.
